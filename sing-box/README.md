# Sing-box 配置变更说明文档

## 概述
本配置文件适用于 **Sing-box** 通用代理平台。当前配置已针对最新版内核特性（特别是 1.15+ 的高性能 TUN 栈）进行深度优化，旨在提供高效、稳定且智能的分流体验。

## 主要变更点

### 1. 核心内核适配 (2026-10-06)
- **TUN 协议栈升级**：全面移除废弃的 `stack` 配置项，默认启用 Sing-box 1.15.0+ 引入的自研高性能 `sing-tun` TCP/IP 协议栈，显著提升吞吐性能与能效。
- **配置语法清理**：删除了已弃用的 legacy DNS 规则语法，确保在新版本下的高稳定性。

### 2. JS 脚本优化 (`sub-store.js`)
- **国旗归一化**：自动将台区国旗 (`🇹🇼`) 统一替换为 `🇨🇳`，保证排版一致。
- **排版修正**：增强正则表达式，自动修复链式代理生成节点时 Emoji 国旗与后续节点名之间丢失空格的问题，确保名称显示美观。
- **策略组扩展**：
  - **日本组 (`jp`)**：新增韩国节点 (`🇰🇷`) 覆盖。
  - **美国组 (`us`)**：新增德国 (`🇩🇪`)、澳大利亚 (`🇦🇺`) 及英国 (`🇬🇧`) 节点覆盖。
- **健壮性**：自动剔除无效 `detour` 依赖，并加入空策略组防护，防止启动报错。
