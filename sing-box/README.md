# sing-box 配置维护与上游更新

> 上游版本核对日期：2026-10-26；规则集链接验证日期：2026-10-24。配置由 `box.json` 与 Sub-Store 脚本 `sub-store.js` 共同生成；完整运行配置取决于订阅节点及脚本处理结果。

## 上游版本

- **最新稳定版：v1.14.4**，发布于 2026-10-24（UTC）。官方发布说明为修复与改进。
- **最新预览版：v1.15.0-alpha.13**，发布于 2026-10-24（UTC）。官方发布说明同为修复与改进；预览版不是生产稳定基线。
- 1.15 预览系列自 alpha.3 起引入 sing-tun 自有 TCP/IP 协议栈，并弃用 TUN 的 `stack` 字段。当前模板没有显式设置该字段；本轮继续不为预览版添加未经验证的行为，也不把预览变化描述为 v1.14.4 稳定版特性。

## 本仓库配置与维护结论

- `box.json` 是含空地区策略组的模板；`sub-store.js` 会填充订阅节点与策略组、清理失效 `detour`，并为无匹配节点的组补入兼容出口。模板不能单独代表订阅生成后的完整运行配置。
- 当前 DNS、路由规则使用非 legacy 的 `action` 语法，规则集使用二进制 `srs` 格式。核查 v1.14.4 与 alpha.13 的官方说明后，没有发现要求本模板改变规则行为或迁移字段的变化，本轮不改动配置或生成脚本。
- `box.json` 中 15 条规则集 URL 已使用 jsDelivr CDN 地址（`https://cdn.jsdelivr.net/gh/MetaCubeX/meta-rules-dat@sing/<path>`）；规则集内容、格式及其余配置保持不变。非规则集用途的 UI 下载地址不在该调整范围。
- 节点名处理与分组逻辑保持不变：台区旗帜统一映射为 `🇨🇳` 并补齐旗帜与名称间的空格；日本组可纳入韩国节点，美国组可纳入德国、澳大利亚及英国节点。

## 校验记录

- **2026-10-26**：使用官方 sing-box **v1.14.4** 执行 `sing-box check`。本轮实际运行 `sub-store.js`，模拟 Sub-Store 接口，分别输入空节点列表和一个测试 SOCKS5 节点；两份生成配置均通过检查，策略组非空且出口引用有效。下载资产 SHA-256 与官方发布值一致。
- **2026-10-24**：对 15 条 jsDelivr 规则集 URL 执行 HTTP Range GET，均返回 `206 Partial Content` 及非空 `application/octet-stream` 数据；用户确认测试 URL 可在手机上下载。

上述检查不等同于真实订阅、规则集完整下载与解析，或目标设备上的 TUN 连通性测试。
