# sing-box 配置维护与上游更新

> 核对日期：2026-10-12。配置由 `box.json` 与 Sub-Store 脚本 `sub-store.js` 共同生成；完整运行配置取决于订阅节点及脚本处理结果。

## 上游版本

- **最新稳定版：v1.14.3**，发布于 2026-10-09（UTC）。发布说明为修复与改进。
- **最新预览版：v1.15.0-alpha.12**，发布于 2026-10-11（UTC）。发布说明为修复与改进；预览版不是生产稳定基线。
- 1.15 预览系列自 alpha.3 起引入 sing-tun 自有 TCP/IP 协议栈，并弃用 TUN 的 `stack` 字段。当前模板没有显式设置该字段；不为预览版新增未验证行为，也不将预览版变化描述为 v1.14.3 稳定版特性。

## 本仓库配置与维护结论

- `box.json` 是含空地区策略组的模板；`sub-store.js` 会填充订阅节点与策略组、清理失效 `detour`，并为无匹配节点的组补入兼容出口。因此，模板不能单独代表订阅生成后的完整运行配置。
- 当前 DNS、路由规则使用非 legacy 的 `action` 语法，规则集使用二进制 `srs` 格式。核查 v1.14.3 与当前预览版发布说明后，没有发现需要为本模板改变行为或迁移字段的理由，本轮不改动 `box.json`。
- 节点名处理与分组逻辑保持不变：台区旗帜统一映射为 `🇨🇳` 并补齐旗帜与名称间的空格；日本组可纳入韩国节点，美国组可纳入德国、澳大利亚及英国节点。

## 校验记录

使用官方 sing-box **v1.14.3** 执行 `sing-box check`，对从 `box.json` 派生的代表性校验配置检查通过。由于仓库模板中的地区策略组有意保持为空，校验样例为这些空组补入了测试用 `direct` 出口；这验证的是模板配置结构，不替代使用真实订阅生成完整配置后的运行测试。
